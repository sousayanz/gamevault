GAMEVAULT — biblioteca pessoal de links

COMO USAR
1. Extraia os arquivos.
2. Abra index.html no navegador.
3. Clique em "Adicionar jogo" e preencha nome, gênero e link.
4. Use o botão "Exportar biblioteca" para fazer backup em JSON.

ARQUIVOS
- index.html: estrutura da página
- style.css: visual e responsividade
- script.js: cadastro, edição, exclusão, busca e armazenamento

IMPORTANTE
- Os jogos e links não são hospedados pelo site.
- Os registros ficam no armazenamento local (localStorage) do navegador/dispositivo.
- Para não perder sua biblioteca, exporte um backup JSON periodicamente.
- Se abrir o site em outro navegador ou dispositivo, importe o JSON exportado.
- Links externos podem expirar ou deixar de funcionar.
- Use links para conteúdo que você tenha autorização para acessar.

PARA PUBLICAR
Você pode subir os três arquivos para um repositório GitHub e ativar GitHub Pages em Settings > Pages.
